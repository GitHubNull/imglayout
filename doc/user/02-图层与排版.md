# 用户教程 · 02 图层与排版

> 前置：[01 快速开始](01-快速开始.md)。本篇讲清图层面板的每个控件和精排版工具。

## 1. 图层面板怎么读

左栏「图层」页签按 Photoshop 习惯排列：**列表顶部 = 画布最顶层**，行首的序号就是叠放次序——**最上面那层序号最大**。

每行从左到右：

1. **序号**：默认显示；点工具行右侧的 `#` 按钮可隐藏/恢复。
2. **眼睛**：切换图层可见性（隐藏的行变淡显示）。
3. **缩略图**：照片小图；变成灰色占位并出现「缺失」徽标时，说明原图文件找不到了。
4. **名称**：未命名时显示原文件名；**双击可重命名**。
5. **锁**：锁定后该图层在画布上不可拖动，防止误碰。

## 2. 排序与搜索

- **搜索框**：按名称过滤图层（支持文件名匹配）。
- **排序组**：四种视图排序——序号↓（默认）、序号↑、文件名↑、文件名↓。
  - 排序只改变**列表视图顺序**，不改变照片的真实叠放次序；
  - 无论怎么排，每行显示的始终是真实堆叠序号；
  - 搜索或排序激活时，拖拽排序会暂时禁用，恢复「序号↓」无过滤状态即可继续拖。

## 3. 调整叠放次序

在图层列表中**按住一行拖拽**，插入线会提示落点，松手即调整上下关系。画布上层的照片会盖住下层。

## 4. 单图层与多图层操作

- 单击选中；**Ctrl+点击**多选（再点一次取消）。
- 选中后底部出现**不透明度滑杆**与**复制图层 / 删除图层**按钮。
- 选中多个图层后，顶栏「编辑」下拉里的 **组合** 按钮把她们编成一组，整体移动、整体对齐；**解组合** 解散。
- 顶栏**对齐**按钮（常驻）：左/水平居中/右、顶/垂直居中/底对齐，对多选或组生效。

## 5. 精排版工具（顶栏「视图」下拉）

下表开关全部集中在顶栏「视图」下拉里，点击展开即可切换：

| 开关 | 作用 |
| ---- | ---- |
| 网格 | 显示/隐藏背景网格，步距可下拉切换（1/2/5/10 毫米） |
| 网格吸附 | 拖动照片时边缘自动吸到网格线 |
| 边缘吸附 | 自动吸附画布边缘与其他照片边缘 |
| 标尺 | 显示/隐藏顶部与左侧标尺 |
| 参考线 | 显示/隐藏从标尺拖出的参考线；拖动照片会吸附参考线 |
| 清除参考线 | 一键清掉所有未锁定的参考线 |

**拖出参考线**：从标尺向画布内拖动即可；参考线选中后可删除或锁定（锁定的不受「清除」影响）。

## 6. 撤销与重做

顶栏弯曲箭头撤销/重做，`Ctrl+Z` / `Ctrl+Shift+Z`（可在快捷键设置里改）。拖动不透明度滑杆等连续操作会合并成一步撤销。
