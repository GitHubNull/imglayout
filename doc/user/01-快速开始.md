# 用户教程 · 01 快速开始

> 本系列面向普通用户，由简入繁共三篇：01 快速开始 → 02 图层与排版 → 03 导出与项目包。
> 软件内顶栏「？」按钮的「使用教程」弹窗是这三篇的精简版，内容保持一致。

## 1. 安装并打开

从 GitHub Releases 下载安装包：Windows 用 `.exe` 安装器，Linux 用 `.deb` 或 AppImage。安装后打开「imgLayout 照片拼接打印工具」，首次进入是一个空画布和左中右三栏界面。

- 左栏：图层 / 照片两个页签
- 中间：画布（带标尺）
- 右栏：输出 / 布局两个页签
- 顶栏：导入、保存、撤销重做、对齐、视图开关、帮助与导出
- 底栏：操作提示、选中信息、缩放控制、保存状态

## 2. 设定画布与排版模式

在右栏「输出」页签设置画布宽 × 高（毫米）、DPI 与背景色——这三个值决定导出图片的打印尺寸，先按你的印品规格设好。

右栏「布局」页签选择排版模式：

| 模式 | 效果 |
| ---- | ---- |
| 网格 | 照片按行列整齐阵列，适合规则照片墙 |
| 瀑布流 | 按列填充、行高自然错落，适合大小不一的照片 |
| 自由 | 不自动排版，照片拖到哪就在哪，适合精修 |

## 3. 导入照片

点击顶栏「导入照片」，可多选图片文件。导入后：

- 「照片」页签出现素材缩略图；
- 「图层」页签同步出现对应图层（顶部是最顶层）。

## 4. 自动排版

网格模式设好行列数、瀑布流模式设好列数，点击「应用布局」，照片自动铺满画布。之后可以再用下一篇的图层工具微调。

## 5. 保存项目

点顶栏保存按钮（默认快捷键见「快捷键设置」）。项目保存为 **.imglayout 单文件包**，内含布局数据与全部照片原图——把这一个文件拷走，换台电脑打开就能继续。
