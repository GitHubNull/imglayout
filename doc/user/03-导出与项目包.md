# 用户教程 · 03 导出与项目包

> 前置：[02 图层与排版](02-图层与排版.md)。本篇覆盖成品导出、工程分享与个性化设置。

## 1. 导出成品图

1. 点顶栏「导出…」按钮。
2. 选择格式：**JPEG**（体积小、可设质量百分比）或 **PNG**（无损、透明背景）。
3. 导出按**画布 DPI** 渲染：画布 300×200 毫米 @300DPI ≈ 3543×2362 像素，直接送印即可得到期望尺寸。
4. 导出中显示合成进度；完成后文件在选定路径。

## 2. 导出前检查

- 图层列表里有「缺失」徽标的照片**不会**出现在成品里——先重新指定原图或删除该图层。
- 画布尺寸、DPI 在右栏「输出」页签随时可改，改完重新导出。

## 3. 项目包：保存与分享

| 操作 | 方式 |
| ---- | ---- |
| 保存 | 顶栏保存按钮（首次会询问路径），生成 `.imglayout` 文件 |
| 另存为 | 顶栏「文件」下拉里的「另存为」换路径存副本 |
| 打开 | 顶栏「文件」下拉里的文件夹按钮选择 `.imglayout` |

`.imglayout` 是**单文件项目包**：布局数据 + 全部照片原图打包在一起。发给别人或拷到另一台电脑，打开即可继续编辑，不需要再传散图。

## 4. 缺图怎么办

打开项目包时若照片在原路径找不到，软件会提示缺失：

- 若包内有原图副本，可直接用副本恢复显示；
- 否则重新选择该照片的位置。

「缺失」是数据层面的标记，不会影响其他图层。

## 5. 自定义快捷键

1. 点顶栏「帮助」下拉里的齿轮按钮打开「快捷键设置」。
2. 点击想改的命令右侧键位按钮，按下新组合键即完成。
3. `Esc` 取消录制，`Backspace` 清除绑定；「恢复默认」一键还原。
4. 空格键固定为「抓手」（平移画布），不可改。

快捷键改动即时生效并自动记忆，下次启动仍有效。

## 6. 更多帮助

- 顶栏「帮助」下拉里的问号按钮随时打开本套教程；
- 顶栏「帮助」下拉里的 `i` 按钮查看软件版本、更新历史与开源协议；
- 遇到问题先更新到最新版本，再看更新历史里有没有相关修复。
