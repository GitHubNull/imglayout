# imgLayout 产品需求文档（PRD）

## 1. 背景与目标

用户手里有多张数码照片，希望拼成**一整张大图**，拿到网上冲印店打印、装裱进相框挂墙（照片墙/单幅大相框）。现有拼图工具（手机 App、在线工具）面向社交分享，输出分辨率低、没有打印尺寸/DPI/出血概念，放大打印会模糊或尺寸不对。

**imgLayout 是一个面向打印的桌面拼接工具**：布局所见即所得，输出按冲印店要求的真实物理尺寸（毫米）和 DPI 渲染，导出一张高分辨率 JPEG/PNG 直接上传冲印。

## 2. 目标用户与场景

- 把家庭照片拼成 20/27/32 寸大相框上墙
- 多张照片拼一张 A4/10 寸冲印送亲友
- 照片墙排版前先在一个文件里规划好整版

## 3. 功能需求

### 3.1 布局模式（三种，全部真实可用）

| 模式 | 说明 |
|------|------|
| 规则网格 | 行×列可配；外边距、内间距；填充方式 cover（裁剪填满，居中锚点）/ contain（完整显示，格内留白） |
| 瀑布流/拼贴 | masonry 按列自动排布，列数、间距可配；后续支持模板化拼贴（1 大 N 小） |
| 自由排版 | 画布上拖动、缩放、旋转照片；层级上下调整；吸附对齐（边界/中线） |

### 3.2 输出规格

- 冲印预设：5 / 7 / 10 / 15 / 20 / 21 / 27 / 32 寸 + A4（毫米对照见 `spec/print-sizes.md`），默认 300DPI，JPEG quality 95，sRGB
- 自定义：宽×高毫米或英寸、DPI 150–600、出血毫米（画面外扩，供冲印裁切）
- 横竖切换：预设支持横向/纵向互换

### 3.3 单张轻编辑

旋转（90° 步进 + 任意角）、水平/垂直翻转、亮度/对比度/饱和度（0–2，默认 1）、圆角半径、边框描边（宽度+颜色）。

### 3.4 画布操作（硬性要求）

大尺寸输出（32 寸 @300DPI ≈ 7200×9600px）必须可操作建议：

- 滚轮缩放（光标锚点，0.05×–8× 连续）
- 中键或 Space+左键拖拽平移；Shift+滚轮横向平移
- 工具栏：适应窗口 / 100% / 放大 / 缩小 / 当前缩放百分比显示
- 所有选中、拖动、手柄操作与缩放级别无关（逻辑坐标 = 毫米）

### 3.5 项目管理

- 导入照片（多选/拖拽），自动生成缩略图用于预览，原图只在导出时读取
- 项目保存/加载（LayoutDoc JSON，见 `layout-schema.md`）
- 导出：异步合成 + 进度条，完成后可打开所在目录

### 3.6 图层管理（PS 式）

- 图层面板：顶层在前；眼睛图标切换可见性；锁定图标锁定画布编辑；双击重命名（默认显示文件名）
- 拖拽排序调整层级，复制图层（Ctrl+J 或底部按钮，副本偏移放置并自动选中）、删除图层
- 选中图层底部不透明度滑杆（0–100%，预览与导出口径一致：整层含边框与背景混合）
- 隐藏层仍参与排版占位但不绘制、不导出；锁定层在画布上禁止移动/缩放/旋转/微调/删除

### 3.7 方向与默认规格

- 输出方向默认**横向**（新建项目 A4 横向 297×210；预设按宽 ≥ 高应用），输出面板「横竖互换」随时切换

## 4. 非功能需求

- 中文 UI
- 构建零告警（clippy / vue-tsc）
- 单文件 ≤500 行
- 平台：Windows / macOS / Linux（Tauri 2）

## 5. 验收标准（M1–M4 对应计划文件）

- M1：空壳应用三个平台构建脚本就绪，`script/check.sh` 全绿
- M2：三种布局算法 + 导出管线，fixtures 集成测试断言输出尺寸与采样像素
- M3：编辑器三种模式实时预览与 Rust 导出结果布局一致；缩放平移可用
- M4：导出 5 寸与 32 寸样图，像素尺寸精确，人工查看无错位
- M5：侧栏左侧布局；工具栏缩放百分比实时显示；输出默认横向；PS 式图层面板（可见性/锁定/重命名/拖拽排序/复制删除/不透明度）预览与导出口径一致
