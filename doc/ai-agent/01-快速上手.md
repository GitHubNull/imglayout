## 环境与首次跑通

前置：Node 20+、pnpm 10、Rust stable。Linux 需 Tauri 系统依赖（webkit2gtk 等）。

```bash
pnpm install
pnpm dev        # Tauri 窗口 + Vite 热更新（前端固定 1420 端口）
pnpm check      # 零告警门禁：clippy -D warnings → fmt → vue-tsc → vite build
pnpm test       # cargo test + vitest
```

一切修改的收口标准：`pnpm check && pnpm test` 全绿。

## 5 分钟代码导览

启动链：`src/frontend/index.html` → `src/main.ts`（PrimeVue 全局注册，**新组件无需 import 直接用**）→ `src/App.vue`（仅主题类切换）→ `src/views/EditorView.vue`（真正的编辑器编排：顶栏/面板/画布/弹窗全在这）。

从这里往下钻：

| 层 | 位置 | 职责 |
| ---- | ---- | ---- |
| 视图 | `views/EditorView.vue` | 编排面板与弹窗，顶栏按钮的挂载点 |
| 组件 | `components/` | panels/（图层面板等）、canvas/（画布+交互控制器）、help/（关于/教程弹窗） |
| 状态 | `stores/` | Pinia：project（文档+撤销栈）、assets、settings、shortcuts |
| 纯函数 | `lib/` | 排版算法（grid/masonry/free/align）、画布主题、快捷键映射、教程数据 |
| 后端 | `src/backend/src/` | Tauri commands：项目包、导出渲染、模型（与前端 types 严格 serde 对应） |

## 改动落点速查

- 新顶栏入口 → `EditorView.vue` header + 新弹窗组件仿 `components/help/AboutDialog.vue`（`defineModel<boolean>` 范式）。
- 新编辑器偏好 → `stores/settings.ts` 加字段 + DEFAULTS（localStorage 自动持久化、旧数据自动补默认）。
- 新文档字段 → 先想清楚：前端 `types/layout.ts` 与 Rust `model.rs` 是 serde 契约，**默认不许动**；派生量从 `doc.items` 计算。
- 新后端命令 → `src/backend/src/commands/` + `capabilities/` 授权 + `src/frontend` 侧 invoke 封装。
