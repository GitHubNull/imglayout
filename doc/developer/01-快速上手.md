# 开发者教程 · 01 快速上手

> 本系列面向参与 imgLayout 开发维护的人类开发者，由简入繁共三篇。
> （另有面向 AI 编程代理的平行版本：[doc/ai-agent/](../ai-agent/)，内容相近；根目录 [AGENTS.md](../../AGENTS.md) 同时约束两者。）

## 拿到代码

```bash
git clone <本仓库地址>
cd imgLayout
pnpm install
```

前置环境：Node.js 20+、pnpm 10、Rust stable；Linux 需安装 Tauri v2 系统依赖（Debian/Ubuntu：`libwebkit2gtk-4.1-dev` 等，参考 Tauri 官方 prerequisites 页）。

## 四个脚本命令

| 命令 | 实际执行 | 典型输出 |
| ---- | ---- | ---- |
| `pnpm dev` | `script/dev.sh` → `pnpm tauri dev` | 先起 Vite（1420 端口）再弹 Tauri 窗口，改前端即时热更新 |
| `pnpm check` | `script/check.sh` | 四步门禁：clippy `-D warnings` → `cargo fmt --check` → `vue-tsc` → `vite build`，任何一步失败即非零退出 |
| `pnpm test` | `script/test.sh` | `cargo test`（Rust 单测+集成测试）接 `vitest run`（13 个 spec） |
| `pnpm build` | `script/build.sh` | 前端产物 + Rust release 二进制 + 安装包（deb/rpm） |

Windows 下没有 bash，双击 `script/build-windows.bat` 即可一键完成同样的流程并打出 NSIS 安装包（前置：Node.js 20+、Visual Studio C++ 生成工具、rustup 默认 msvc 工具链，缺什么脚本会中文提示）。

## 首次跑通检查清单

1. `pnpm dev` 能弹出窗口、导入照片、拖拽排版；
2. `pnpm check` 全绿（本项目零告警是硬标准，你的环境跑不过通常说明工具链版本不对）；
3. `pnpm test` 全绿；
4. 若 webkit 依赖缺失导致 dev 起不来，先装系统依赖再重试——不要用降低 webkit 版本的方式绕过。

## 常见环境问题

- **Rust 编译慢**：首次全量编译正常；`script/check.sh` 的 clippy 也会编译一遍，耐心等。
- **1420 端口被占**：上一次 dev 没退干净，`pkill -f "vite"` 或换端口前先检查残留进程。
- **代理环境**：cargo/pnpm 走代理失败时检查 `HTTP(S)_PROXY` 变量。
